Interview Coder

Codes an interview transcript against your codebook, using your coded exemplars as the model. Runs in your browser; files go only to the Anthropic API.

1. Files

2. Settings

Consensus mode codes the transcript several times, each run with a different seeded exemplar order (and, if ticked, one exemplar left out), then keeps a code only if enough runs applied it. Cost grows with the number of runs, because each run sends the full codebook and exemplars (about 70,000 tokens).

Temperature is fixed at 0. The API has no sampling seed, so the seed here sets the exemplar order, and every run saves a manifest with file hashes so others can verify they used the same inputs.
